Before you start

Where and how

  • Open Pre-Prod at wberp-pre-prod.up.railway.app. Never test in the live system.
  • Sign in with the login made for your role. Ask the administrator if you do not have one. Do not share a login — every action is recorded against the name that did it.
  • Pick WBE — WB Engineering in the company switcher unless a step says otherwise. The test records are there.
  • Test records are clearly marked: items and stores start with T-, and notes say [test data]. Examples: supplier Emirates Cable Trading LLC, customer Deep Port Logistics FZC, item T-CBL-4C16 (4-core cable), store T-MAIN (Main store, Mussafah, with bins A-01 to E-02).
  • Anything you create, name it with your initials, e.g. "AK test — cable for pump house", so it can be found later.
  • The ? button in the top bar explains the screen you are on. Use it before marking something failed because it seems strange.

Recording a result

ResultUse it when
PassWhat happened matches the expected result.
FailIt did something different, showed an error, or showed a wrong figure. Say exactly what you saw in the note — the screen, the figure, the message word for word.
BlockedYou could not run it — missing login, missing access, or an earlier step failed.
SeverityMeaning
CriticalWrong money, wrong tax, data lost, or someone can see or do what they must not. Stops go-live.
MajorThe task cannot be done, or can only be done with a workaround a normal user would not find.
MinorThe task can be done but something is confusing, slow, or badly worded.
SuggestionWorks as designed, but you would like it to work differently.

Your results stay in this browser on this device. When you finish a session, press Download results and send the file to the project team.

The two flows the roles hand to each other

Some checks depend on another person finishing theirs first. The note under each check says which.

Site Engineer raises a material request→Site Engineer / Planner, Project Manager and Procurement approve — never the person who raised it, and never one person for two steps→Procurement gets 3 quotes and awards→PM, Operations, Director approve the order→Storekeeper receives→QA/QC inspects→Storekeeper issues to the job→Finance sees the cost on the job
Estimator logs an enquiry and prices it→Estimator raises the quotation→Operations Manager, Director approve→Estimator emails it→Customer orders: job created→Finance invoices
Every expected result on this page was checked against the system's own rules and screens before it was written. If the system and this page disagree, record it as a failure and say so in the note — either the system or the page is wrong, and both matter.
